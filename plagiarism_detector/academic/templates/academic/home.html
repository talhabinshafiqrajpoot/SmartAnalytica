Content detection and analysis for programming assignments

SmartAnalytica compares every submission for an assignment against every other one, using lexical, structural and semantic analysis, and produces a report that shows not just a percentage but the passages that matched and who they matched.

Lexical analysis

Jaccard, Longest Common Subsequence, Levenshtein, Cosine and Rabin-Karp fingerprinting locate shared vocabulary and verbatim copied passages.

Structural analysis

Code is parsed into a structure-only token stream and fingerprinted with winnowing, so renaming variables or reordering functions does not hide a copy.

Semantic analysis

Sentence embeddings compare meaning rather than wording, catching paraphrasing that every word-matching algorithm misses.
